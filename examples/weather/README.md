# Weather MCP Server

A weather server demonstrating resources, templates with completion,
prompts with arguments, discoverability, and multiple transports.

**Features:** `get_weather` + `get_forecast` tools with full wayfinding,
static resource + URI template with city completion, prompt with
argument completion, directory tool, stdio + tcp transports.

**Run:** `./examples/weather/run.sh`

See [examples/README.md](../README.md) for Claude Desktop config,
feature coverage, and test commands.
